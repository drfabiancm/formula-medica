FÓRMULA MÉDICA — PWA PARA iPHONE

Archivos:
index.html
manifest.json
sw.js
firma.png
icon-180.png
icon-512.png

PUBLICACIÓN:
1. Sube todos los archivos a un hosting HTTPS.
2. Abre la dirección HTTPS en Safari del iPhone.
3. Pulsa Compartir → Añadir a pantalla de inicio.
4. Abre la app desde el nuevo icono.

La PWA necesita HTTPS para instalarse correctamente y el funcionamiento
offline se activa después de la primera carga.
